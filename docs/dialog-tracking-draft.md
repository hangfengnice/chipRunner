# 对话跟踪底稿

这份底稿可用于在新对话中继续沿用同一套跟踪和计算流程。

## 用途

基于固定模型参数持续计算策略结果，并将每日实盘数据与模型目标数据进行对照。

## 当前模型参数

- 初始持股：`4900`
- 初始现金：`2313.83`
- 固定价格：`25.35`
- 每股每日可获取差价：`0.4`
- 每手成本：`2535`
- 这一套参数从 `2026.06.01` 作为第一个交易日开始计算
- 展示时尽量优先使用实际日期，而不是单纯的第几天

## 计算规则

- 每日做T利润 = 开盘持股 x `0.4`
- 盘后现金 = 前一日现金 + 当日做T利润
- 如果盘后现金 >= `2535`，则按整手尽可能买入
- 收盘总资产 = 收盘持股 x `25.35` + 收盘现金

## 输出表头偏好

返回详细跟踪表时，使用以下固定列顺序：

`日期`
`目标股`
`做T利润`
`目标现`
`目标资产`
`实盘股`
`实盘现`
`做T差额`
`收盘价`
`实盘总资产`
`股数差额`
`资产差额`
`目标对应日期`
`进度差`
`总资产百分比`

## 差额规则

- `做T差额 = 实盘现 - 目标现`
- 如果实盘现金高于目标现金，显示 `+金额 ↑`
- 如果实盘现金低于目标现金，显示 `-金额 ↓`

## 百分比规则

- `总资产百分比 = 实盘总资产 / 目标资产 x 100%`

## 进度定位规则

- 如果用户只提供 `当前总资产`，默认取 `实盘股 = 当天目标股`，再结合 `收盘价` 反推出 `实盘现`。
- 额外可给出两个简化字段：
  - `目标对应日期`：当前总资产在目标总资产序列中首次达到的日期
  - `进度差`：相对当前日期的交易日差，使用 `提前N天`、`落后N天` 或 `正好当天` 表示

## 实盘数据输入格式

每日实盘数据可按下面格式提供：

```text
2026.06.01
实盘股：xxxx
实盘现：xxxx
收盘价：xx.xx
```

## 回复展示偏好

- 优先使用适合聊天窗口阅读的清晰展示方式，避免特别大的宽表
- 默认输出形式：
  - 当前更新后的这一行
  - 后续 10 个交易日的模板行
  - 如有必要，再补一条简短总结
- 如果明确要求批量导出，则优先提供紧凑的 CSV 风格输出
